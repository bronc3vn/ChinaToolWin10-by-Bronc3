# AndroidChinaTool V1.0.0

🚀 **Phiên bản đầu tiên của AndroidChinaTool by Bronc3**

AndroidChinaTool là công cụ dành cho Windows, hỗ trợ thao tác và thiết lập thiết bị Android với giao diện đơn giản, thuận tiện cho người dùng.

## 📦 Thông tin phiên bản

- **Tên:** AndroidChinaTool
- **Phiên bản:** V1.0.0
- **Developer:** Bronc3
- **Nền tảng:** Windows
- **File:** `AndroidChinaTool_V1.exe`

## 💻 Yêu cầu

- Windows 10/11
- Máy tính có cổng USB
- Cáp USB phù hợp khi cần kết nối thiết bị Android

## 📥 Cách cài đặt / sử dụng

1. Tải `AndroidChinaTool_V1.exe` trong phần **Assets** bên dưới.
2. Mở file sau khi tải hoàn tất.
3. Nếu công cụ cần giao tiếp với điện thoại, kết nối thiết bị Android với máy tính.
4. Thực hiện theo hướng dẫn hiển thị trong phần mềm.

## ⚠️ Lưu ý

Chỉ sử dụng các chức năng bạn hiểu rõ và nên sao lưu dữ liệu quan trọng trước khi thực hiện những thay đổi hệ thống trên thiết bị.
